## Key lines to say

- We help development teams screen, manage and monitor grid-connected projects.
- This is the development portfolio in one workspace.
- This is your development portfolio on a map — not a capacity map.
- The project is sample data. Official context is from NOXHEIM’s current official dataset.
- Readiness is workflow completeness, not site feasibility.
- Compare is portfolio triage from team/workflow factors — not an AI recommendation.
- Empty Changes is correct: official baseline established; later snapshots can be compared.

## What not to say

- Available capacity / headroom / “40 MW can connect”
- Capacity map / best places to build
- Operator approval / official case status
- AI site score
- That landing Sample frames are this live workspace

## Backup plan

- If a project page fails: stay on Overview + Map; use Uppsala Storage (`/projects/uppsala-storage`).
- If Grid Intelligence is empty at a coordinate: do not invent context; switch to Stockholm North BESS.
- If Changes looks empty: that is the truthful baseline — explain the architecture, do not invent a change.
- If login fails: use the landing Sample preview and reschedule the live workspace.

## What is sample vs official

- **Sample:** projects, MW, team outlook/confidence, connection cases, requirements, document metadata.
- **Official:** Ei local-network geography and NUP / forecast need matched to each coordinate.
- **NOXHEIM-derived:** readiness %, Development Profile triage, attention counts from customer workflow.
