## Key lines to say

- We help development teams screen, manage and monitor grid-connected projects.
- This is your development portfolio on a map — not a capacity map.
- Candidate Sites and Evidence Coverage are Noxheim-derived from official geography.
- Requested MW, outlook, and connection cases are customer-entered.
- Readiness is workflow completeness, not site feasibility.
- Empty Changes is correct until a later official snapshot differs.

## What not to say

- Available capacity / headroom / “40 MW can connect”
- Capacity map / best places to build
- Operator approval / official case status
- AI site score
- That landing Sample frames are this live workspace

## Backup plan

- If Discovery is empty: stop. Do not invent Candidate Sites. Reschedule after `demo:preflight`.
- If Grid Intelligence is empty at a coordinate: do not invent context; switch to Stockholm North BESS.
- If Changes looks empty: that is the truthful baseline.
- If login fails: use the landing Sample preview and reschedule the live workspace.

## What is sample vs official vs derived

- **Customer entered:** projects, MW, team outlook/confidence, connection cases, requirements, document metadata.
- **Official:** Ei local-network geography and NUP / forecast need matched to coordinates.
- **Noxheim derived:** Candidate Sites, recommendation, Evidence Coverage, readiness %, attention.
